# User settings

Profile and Personalization contain user-scoped information and preferences. Treat displayed identity, contact, notification, secret, key, and device information as private.

## Profile

Profile can contain identity fields, profile image, bio, account export, account secrets, SSH keys, experimental-access settings, sign-out controls, and account deletion.

- Inspect without repeating private values.
- Obtain confirmation before changing profile fields, uploading an image, exporting data, creating a secret, adding an SSH key, changing experimental access, signing out devices, or requesting account deletion.
- Treat account deletion as irreversible and require an explicit user request at the final step.

## Personalization

Personalization can control language and region, Agent notifications and send behavior, preview behavior, appearance, email and production alerts, code-editing settings, and developer settings.

Explain the affected behavior before changing any switch, selection, or notification preference. Obtain confirmation immediately before saving or applying a change.
