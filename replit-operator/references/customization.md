# Customization

Open workspace Settings, select **Customization**, and wait for its tabs to render. Verify the selected tab before interpreting or changing its contents.

## Skills

The Skills tab can show enabled state and searchable skill entries. Its **Add** menu provides:

- Write a skill: name, description, and instructions; creating the skill is an external workspace change.
- Upload a skill: requires file-upload approval.
- Add from GitHub: accepts a public repository, folder, or file URL, then previews its structure before import.
- Browse skill library: opens the skill library.

Inspect these surfaces freely. Ask before creating, uploading, importing, enabling, disabling, or otherwise changing a skill.

## Memory

Memory stores preferences for later Replit conversations. The tab exposes a workspace memory switch, a separate shared-projects switch, an editable memory field, and an explicit save action.

Treat existing memory content as private. Do not repeat it unnecessarily. Ask for confirmation before changing a switch, editing memory, or saving changes.

## Instructions

Custom instructions are always-on workspace guidance for Agent. The UI states that they apply to every conversation and project in the workspace and take effect immediately after saving.

Treat instruction edits as high-impact configuration. Explain their workspace-wide scope and obtain confirmation immediately before saving.
